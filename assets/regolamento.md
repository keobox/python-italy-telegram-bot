# Regolamento del gruppo Python Italia

Benvenuto nella community Python Italia!

## Comportamento

- Rispetta tutti i partecipanti
- Evita spam e messaggi ripetuti
- Usa la lingua italiana per le discussioni principali

## Comando segreto

Per completare la verifica e poter partecipare, invia il seguente comando al bot in chat privata:

```
python-italy
```

(Modifica questo file con le regole reali del gruppo e cambia il comando in `.env` se necessario.)
